### Migration du Dépôt Principal

En accord avec nos principes de transparence, d'indépendance technologique et de souveraineté numérique, le code source de l'application **T2DECODE** n'est plus hébergé ni maintenu sur GitHub. 

#### À Propos de T2DECODE

T2DECODE n'est pas une simple application, c'est une véritable **plateforme d'apprentissage technique et de cybersécurité** structurée autour d'un principe non-négociable : un fonctionnement strictement hors-ligne (Air-Gapped / Zéro Cloud).

L'application inclut :
- **Des Simulateurs Intégrés** : Réseau (NetKit), Système, Cryptographie, et Sécurité, permettant d'expérimenter de manière sécurisée sans aucune connexion.
- **Une IA Locale (Ghost AI)** : Un tuteur intelligent fonctionnant directement et localement sur votre machine, éliminant toute fuite de données vers des serveurs tiers.
- **Une Boîte à Outils Complète** : De l'analyse réseau à la conversion de données, un environnement tout-en-un.

#### Pourquoi GitLab ?

Le choix de quitter GitHub pour GitLab repose sur notre volonté de nous affranchir des écosystèmes centralisés et propriétaires. L'ADN de T2DECODE exige une rigueur absolue quant au contrôle des données. En migrant vers une infrastructure orientée Open Core, nous alignons notre environnement de développement collaboratif avec les valeurs éthiques que défend notre plateforme.

Toutes les nouvelles versions (*releases*), la gestion des bugs (*issues*), le code source et la documentation officielle sont désormais exclusivement accessibles sur notre espace GitLab.
