## 🔀 Migration du dépôt principal

En accord avec nos principes de transparence, d'indépendance technologique et de souveraineté numérique, le code source de l'application **T2DECODE** n'est plus hébergé ni maintenu sur GitHub. Toutes les futures mises à jour, issues et contributions se font désormais sur GitLab.

## 🎯 À propos de T2DECODE

T2DECODE n'est pas une simple application : c'est une véritable **plateforme d'apprentissage technique et de cybersécurité**, structurée autour d'un principe non négociable — un fonctionnement strictement **hors-ligne (Air-Gapped / Zéro Cloud)**.

Conçue comme un **simulateur éducatif** pensé pour les parcours techniques (BTS SIO, BUT Informatique, autodidactes...), elle transforme n'importe quelle machine en laboratoire d'analyse sûr et souverain, sans dépendre d'aucun service en ligne.

### ✨ Fonctionnalités clés

- 🛡️ **Suite pédagogique complète** : réseau, système, cybersécurité
- 🔌 **Architecture 100% offline-first**, compatible environnements *air-gapped*
- 🧰 **Plus de 15 outils d'administration système** intégrés
- 🌐 **Simulateur OSI interactif** et modules réseau pour visualiser les concepts complexes
- 💬 **Ghost Link** : système de chat LAN en P2P, sans passer par le cloud
- 🤖 **Tuteur IA local** (RAG via Ollama), fonctionnant entièrement en local
- 🔓 **Aucune télémétrie**, code source libre sous licence **GPLv3**
- 💻 **Multiplateforme** : Linux (AppImage/DEB), macOS, Windows et Android

### 🏗️ Développement

T2DECODE est développé en **Flutter**, ce qui permet de proposer des binaires natifs pour l'ensemble des plateformes cibles à partir d'une base de code unique.
