User ➔ Comment fonctionne la commande ping en réseau ?
Ghost AI ➔ La commande ping utilise le protocole ICMP (Internet Control Message Protocol) en envoyant un paquet ICMP Echo Request (type 8) à l'hôte cible. L'hôte répond avec un paquet ICMP Echo Reply (type 0), ce qui permet de mesurer la latence aller-retour (RTT).

Questions Fréquentes

Informations techniques sur le projet.

Qui a créé T2DECODE ?
T2DECODE a été créé par Maxime MARTIN CIVET (alias winancher / itswinancher), fondateur et président de l'association TUTODECODE. Technicien d'intervention et étudiant en BTS SIO, basé dans les Bouches-du-Rhône, France. Retrouvez son site personnel sur winancher.dev.
T2DECODE fonctionne-t-il vraiment sans internet ?
Oui. T2DECODE est une application native autonome qui s'exécute directement sur votre machine. Aucun serveur distant, aucune API en ligne, aucune connexion réseau requise. L'option IA (via Ollama) est également 100% locale.
Quels systèmes d'exploitation sont supportés ?
Windows (.exe), macOS (App Store / .dmg), Linux (.AppImage / .deb), Android (F-Droid / .apk / .aab) et iOS.
T2DECODE collecte-t-il des données personnelles ?
Non. Politique de zéro télémétrie absolue. Aucune donnée ne quitte votre machine. Le code source est auditable sur GitLab sous licence GPLv3.
T2DECODE est-il gratuit ?
Oui, entièrement gratuit et open source sous licence GPLv3. Édité par l'association loi 1901 TUTODECODE, sans but lucratif.
