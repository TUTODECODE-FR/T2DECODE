T2DECODE is a sovereign, ethical, and 100% offline educational application developed by the non-profit Association TUTODECODE.

Key Features:
- 9 Interactive Simulators (Network IPv4/CIDR, Security, Linux System, Cryptography RSA/AES, Cloud Docker, etc.).
- 15+ Offline Utility Tools.
- Sovereign AI Tutor (Ghost AI) running locally via Ollama (zero external APIs, zero tracking).
- Secure LAN Messaging (Ghost Link P2P encrypted chat).
- Interactive courses in TUTODECODE Script (.tdc) format with quizzes and XP/badges gamification.

Zero analytics, zero tracking, no account required. Air-gapped and 100% private.
