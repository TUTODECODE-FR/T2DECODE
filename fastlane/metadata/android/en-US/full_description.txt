Note: The application interface is currently in French only.

T2DECODE is a local-first learning platform designed for IT enthusiasts, cybersecurity students, and network administrators.


Features:
- Privacy-focused: Fully functional offline, no telemetry, no tracking, and includes a global offline mode.
- Interactive Labs: Network, System, Cloud, and Cryptography simulators.
- Local AI Assistant: Integrate with local Ollama models (Phi-3, Llama 3) for an air-gapped AI tutor.
- P2P Communication: GhostLink allows local LAN encrypted communication without servers.
- Offline Tools: Built-in utilities (Subnet calculators, Hash generators, CRON helpers, and more).
- Network Diagnostics: Optional real network tools (ping, DNS lookup, TCP connect diagnostics).
- Optional Sync: Download additional course modules directly from the official GitHub repository.
