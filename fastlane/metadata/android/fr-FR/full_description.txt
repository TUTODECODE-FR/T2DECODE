T2DECODE est une plateforme d'apprentissage locale, conçue pour les passionnés d'informatique, les étudiants en cybersécurité et les administrateurs réseau.

Fonctionnalités :
- Respect de la vie privée : Fonctionne principalement hors-ligne, aucun tracking, aucune télémétrie, et inclut un mode hors-ligne global.
- Laboratoires interactifs : Simulateurs de Réseau, Système, Cloud et Cryptographie.
- Assistant IA Local : Intégration avec vos modèles Ollama locaux (Phi-3, Llama 3) pour un tuteur IA isolé du réseau.
- Communication P2P : La fonctionnalité GhostLink permet des communications chiffrées en LAN sans serveur central.
- Outils intégrés : Utilitaires hors-ligne (Calculateurs de sous-réseaux, Générateurs de hash, Aides CRON, etc.).
- Diagnostics réseau : Outils de test réseau réels optionnels (ping, DNS, connectivité TCP).
- Synchro optionnelle : Téléchargez des modules de cours additionnels depuis le dépôt GitHub officiel.
