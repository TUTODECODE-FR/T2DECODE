## Proposition

**Titre** : commencez par `[Proposition]` (prérempli si possible).

Décrivez l’idée en quelques lignes (contexte, besoin, impact attendu).

### Ce que ce n’est pas

- **Pas** une prise de tâche : pour *prendre* une issue existante, ouvrez une MR
  titrée exactement `prendre #<iid>` (voir [VOLUNTEER_BOARD.md](../../VOLUNTEER_BOARD.md)).
- Merger cette issue **ne** vous assigne **pas** : seul le merge d’une MR `prendre #N` assigne.

### Labels

`benevolat` · `proposition` · `wishlist` (préremplis via ce modèle).

Type GitLab (Incident / Issue / Task) : laissez **Issue** ; le type **Task** est optionnel pour un suivi de travail, il ne remplace pas labels ni claim.
